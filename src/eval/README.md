# 评测系统说明

## 怎么跑

```bash
cd /c/code/MHWI_agent
PYTHONPATH=src .venv/Scripts/python.exe src/eval/run_eval.py
```

## 整体流程

1. `cases.jsonl` 是你手写的题库
2. `run_eval.py` 逐条把 `question` 丢给 Agent
3. Agent 正常跑一遍，脚本从过程中抓出答案、命中的编号、路由、轮数
4. 拿命中的编号和题库要求的编号对比，算覆盖率
5. 结果存进 `results/时间戳.jsonl`，跑一次存一个

## 题库字段（cases.jsonl，一行一条题）

### question
考题。玩家会怎么问，就用大白话怎么写，别写成「查询某武器的制作素材」这种。
**系统读：是**，这就是要喂给 Agent 的问题。

### required_doc_ids
这道题**必须命中**哪几条数据，写程序里的真编号（形如 `weapon|大剑|赤翼Ⅰ`）。
**这是算覆盖率的唯一依据。** 编号必须和数据里一字不差——手打很容易出错，比如把罗马数字 `Ⅰ` 打成英文 `I`，看着一样，程序眼里毫不相干。
**系统读：是。**

### required_units
同一件事的人话版，给你自己看的。
**系统读：否。**

### key_facts
最终答案里**必须出现**的关键事实点。
程序**不自动比对**——因为答案里可能有空格，也可能写「5 个」而不是「×5」，同一个意思不同写法，自动比对会误判。这是给你人工判分时对照用的。
**系统读：否**，人工用。

### difficulty
难度分档：`single-hop`（一次检索够）、`two-hop`（要两步推理）、`multi-hop-fuzzy`（问得含糊）。
它描述的是「用户这题要几步推理」，不是「要查几个库」——查几个库由 `required_doc_ids` 体现，两个字段各管一件事。
**系统读：否。**

### tags
这题涉及哪些库。常见值：`weapon` / `equipment` / `material` / `monster`。
**系统读：否。**

## 结果字段（results/时间戳.jsonl，一行一条）

前 6 个字段（`question`、`required_doc_ids`、`required_units`、`key_facts`、`difficulty`、`tags`）是题库原样带过来的，下面只说新加的。

### agent_answer
系统最终给出的回答原文。**人工判分看这个。**

### retrieved_doc_ids
这次跑下来，所有轮次里实际命中的编号，拉平成一个列表。
拿它和 `required_doc_ids` 求交集，就是覆盖率。

### routed_dbs
它去查了哪几个库，按顺序去重。用来判断路由对不对。

### iterations
一共检索了几轮。轮数明显多，说明它在反复查，可能是在绕圈。

### coverage
覆盖率 = 命中的编号数 ÷ `required_doc_ids` 的条数。0 到 1 之间的小数。
程序自动算。

### missing_doc_ids
`required_doc_ids` 里没被命中的那些编号。
**这个字段比覆盖率本身有用**——覆盖率只告诉你「丢了多少分」，它直接告诉你「丢的是哪一条」。

### human_score
你自己填的分数。现在都是 `null`，等你填。

### fail_category
你自己填的失败原因，五选一：

- `coverage` —— 该找到的资料没找到
- `premature_stop` —— 该继续搜，它停了
- `routing` —— 库选错了
- `iteration` —— 绕太多圈
- `fact` —— 答案里有数据里查不到的东西

## 三个指标

1. **覆盖率**（程序自动算）—— 该拿的数据，拿到了没有
2. **答案对不对**（人工，对着 `key_facts` 读）—— 还没开始填
3. **该停的时候停没停**（人工，看 `iterations` 和 `fail_category`）—— 还没开始填

## 出题的规矩

1. **出题前先去 `data/` 里搜一下名字在不在。** 数据里没有的东西，题目写得再好也测不出系统的水平，只会得到一条没用的失败记录。
2. **编号原样复制，别手打。**
3. **答案不唯一的题不要出。** 比如「某素材能拿来做啥」，能用的武器太多，`required_doc_ids` 根本列不全，没法判。
4. **一行一条，别写成多行 JSON。** 换行符就是这条文件的分隔符。

## 现在还没做的

- 一条题崩了，整个评测会中断，前面跑的结果也保不住
- 没记每条题的耗时
- 结果是全部跑完才写盘，不是边跑边存
